Назначение модулей



1. main.py: Обрабатывает пользовательский ввод, вызывает методы БД, выводит результаты. Реализует цикл командной строки, управление текущей таблицей, парсинг сложных фильтров и аргументов. Содержит класс DatabaseCLI.



2\. database.py: Содержит два основных класса:



* Table - представляет отдельную таблицу, хранит записи в dict, управляет идентификаторами. Реализует операции insert, get\_by\_id, filter, get\_all, update, delete, count, clear.



* Database - управляет несколькими таблицами, позволяет создавать, удалять, переключаться между таблицами. Содержит предопределенные схемы таблиц (students, books, employees).



3\. models.py: Определяет dataclass Student с полями: id, name, age, major, enrolled\_at. Содержит методы для сериализации/десериализации.



4\. errors.py: Кастомные исключения: DatabaseError (базовое), RecordNotFoundError (запись не найдена), ValidationError (ошибка валидации данных).



5\. validators.py: Функция validate\_student\_data для проверки имени, возраста, специальности.







Реализованная функциональность



Управление таблицами:



1. Создание таблиц: команда create <имя> <схема> (доступные схемы: students, books, employees)



2\. Просмотр таблиц: команда tables - показывает все существующие таблицы



3\. Переключение таблиц: команда use <имя\_таблицы> - выбирает активную таблицу



4\. Удаление таблиц: команда drop <имя\_таблицы> - удаляет таблицу со всеми данными







CRUD операции (над текущей таблицей):



1. Добавление записей: команда add поле1=значение1 поле2=значение2 ... с автоматической валидацией типов



2\. Чтение всех записей: команда list - показывает все записи с временными метками



3\. Чтение по ID: команда get <id> - показывает конкретную запись



4\. Обновление записей: команда update <id> поле1=значение1 ... - обновляет указанные поля



5\. Удаление записей: команда delete <id> - удаляет запись







Расширенная фильтрация:



1. Команда filter поддерживает операторы для гибкого поиска:



2\. Точное совпадение: filter поле=значение



3\. Больше чем: filter поле\_\_gt=значение



4\. Меньше чем: filter поле\_\_lt=значение



5\. Содержит: filter поле\_\_contains=подстрока



6\. Начинается с: filter поле\_\_startswith=префикс








Сортировка:



1\. Сортировка по возрастанию: sort <поле>




2\. Сортировка по убыванию: sort <поле> desc




Поддерживаемые поля: любые поля схемы таблицы (строки, числа, ID)









Обработка ошибок:



1. Некорректный ввод данных (пустые поля, неверные типы)



2\. Обращение к несуществующим записям или таблицам



3\. Неверный формат команд и аргументов



4\. Фильтрация по неподдерживаемым полям или операторам



6\. Сортировка по несуществующему полю



5\. Все ошибки перехватываются и выводятся понятным сообщением







Дополнительные возможности:



1. Автоматические временные метки: каждая запись имеет created\_at и updated\_at



2\. Валидация типов: при добавлении и обновлении проверяется соответствие типов схеме таблицы



3\. Подтверждение удаления: при удалении таблицы запрашивается подтверждение



4\. Демо-данные: при первом запуске создаются тестовые таблицы с примерами записей



5\. Регистронезависимая сортировка строк
